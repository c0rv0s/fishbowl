# Glass Aquarium app icon

An amber and pearl Murano glass fish inside a clear glass lens, against deep teal with a warm ivory background. The larger fish and stronger contrast keep the subject readable on the Home Screen.

- Production asset: [AppIcon.png](../../Fishbowl/Assets.xcassets/AppIcon.appiconset/AppIcon.png), 1024 × 1024 opaque RGB PNG.
- Original generated artwork: [murano-fish-master.png](murano-fish-master.png), 1254 × 1254.
- [Generation prompt](prompt.md), using the built-in image generation tool.
- [Previous icon](previous-icon.png) retained for reference.
- [Home Screen before](home-before.png) and [after](home-after.png), captured from the iPhone 17 Simulator.

The existing AppIcon asset catalog entry is unchanged. The generated square was resized and exported as RGB without transparency or a baked corner mask. The Simulator app and widget build passed, and the installed Home Screen icon was visually checked. No physical-device installation or store submission was performed.
